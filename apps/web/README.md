# RightsRail web app

Phase 2 supplies only the typed integration boundary. The premium rights-control interface is deferred to Phase 3.

Planned surfaces are Landing, Rights Dashboard, Policy Creator/Detail, Usage Request, Evidence Comparison, Semantic Matrix, Adjudication Detail, Permit Detail, Settlement History, Activity/Audit, and Integration/Docs.

The primary visual moment will compare `PROTECTED / PERMITTED USE` against `PROPOSED ACTUAL USE`, with semantic differences visible before the deterministic result. The UI must consume canonical API/read-model data and must not fabricate adjudications, permits, or settlement status.

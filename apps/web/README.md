# RightsRail web app

The web app is a premium local product shell for the frozen RightsRail
contract candidate. It runs on port 3001 and is explicitly marked
`CONTROLLED LOCAL` / `UNDEPLOYED` throughout the operator experience.

Routes include Landing, Rights Dashboard, Policy Creator/Detail, Usage Request,
Evidence Comparison, Semantic Matrix, Adjudication Detail, Permit Detail,
Settlement History, Activity/Audit, Integration/Docs, and the controlled
four-case demo.

The primary visual moment compares `PROTECTED ASSET` against `PROPOSED USE`.
All data comes from the explicit local provider through the API. The frontend
does not derive a conflicting verdict and does not fabricate canonical state.

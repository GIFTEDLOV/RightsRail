# RightsRail web app

The premium rights-control interface is intentionally deferred. Planned surfaces are Landing, Rights Dashboard, Policy Creator/Detail, Usage Request, Evidence Comparison, Semantic Matrix, Adjudication Detail, Permit Detail, Settlement History, Activity/Audit, and Integration/Docs.

The primary visual moment will compare `PROTECTED / PERMITTED USE` against `PROPOSED ACTUAL USE`, with semantic differences visible before the final deterministic result.

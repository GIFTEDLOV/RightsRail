# Controlled four-case demo

The demo uses only project-created SVG fixtures under
`apps/web/public/demo/`. The reference is an original Lumen Finch studio card;
the editorial, betting, missing-context, and unrelated images are controlled
variants. No third-party artwork or logo is used.

Open `/demo` and choose a case. Every case is labeled `CONTROLLED LOCAL
QUALIFICATION` and every detail page carries the local/undeployed provenance.

The cases are not network adjudications. They are stable read-model fixtures
that qualify presentation, evidence binding, semantic display, deterministic
outcome rendering, permit behavior, and entitlement allocation.
